PART 7: AUTH MIDDLEWARE
════════════════════════════════════════════════════════════════

Create file: lib/api/middleware/auth.ts

Extend Express Request type:
  declare global { namespace Express { interface Request {
    userId: string; userRole: string; } } }

requireAuth middleware:
  1. Read Authorization: Bearer {token} header
  2. Verify with jwt.verify using process.env.JWT_SECRET
  3. Attach req.userId and req.userRole
  4. On TokenExpiredError: 401 with 'Your session has expired'
  5. On any other error: 401 with 'Invalid token'
  6. On success: write to auditLogs (non-blocking, fire and forget)

generateToken(userId, role):
  accessToken: 15 min expiry signed with JWT_SECRET
  refreshToken: 7 day expiry signed with JWT_SECRET
  Return both

GET /api/points/balance

Create file: lib/jobs/scheduler.ts using node-cron.

JOB 1 — Nightly at 2 AM: Opportunities Engine
  For every active user:
    Mark userOpportunities as MISSED where windowEnd < today

    Assign them with 30-day window

  Insert new window: windowStart=first day of month,

  Insert REDEMPTION_WINDOW_OPEN notification for all active users

JOB 3 — Daily at 9 AM: Closing Warning
  Check if active window ends tomorrow
  If yes: insert REDEMPTION_WINDOW_CLOSING notification for all users

JOB 4 — Jan 1 at midnight: Annual Points Reset
  For every user:
    Log a RESET transaction for their current balance
    Set currentBalance=0, earnedThisYear=0
  Set all hsaAccounts ytdContribution='0.00'

REPLIT-SPECIFIC NOTES — READ THESE
════════════════════════════════════════════════════════════════

1. No Redis in this implementation. All data comes directly
   from PostgreSQL. Do not install ioredis or @upstash/redis.
   Performance is fine without it at this stage.

2. This is a pnpm monorepo. Install mobile-only packages
   (react-native-mmkv etc) from inside artifacts/mobile.
   Install backend packages at the monorepo root.

3. DATABASE_URL is already in Replit Secrets. Never hardcode it.

4. Set ssl: false on the pg Pool — Replit dev does not need SSL.

5. Run drizzle-kit push from the monorepo root, not from inside
   a subfolder.

6. The seed file must be safe to run multiple times.
   Always check before inserting — skip if already exists.

7. tsx is required to run TypeScript files directly.
   Use tsx lib/db/seed.ts not ts-node.
