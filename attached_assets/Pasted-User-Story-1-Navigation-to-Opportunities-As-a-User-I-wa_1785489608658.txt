User Story 1: Navigation to Opportunities
As a User,
I want to navigate to the Opportunities section and select either Care of Site Alternatives or Care Protocol,
So that I can access and view the specific workflows associated with each path.
Acceptance Criteria:
When I click on either Care Site Alternatives and Care Protocol.
Selecting either option must seamlessly route the user to its corresponding page/workflow.
User Story 2: Care of Site Alternatives Workflow UI
As a User,
I want to view the corresponding workflow of the items under Care Site Alternatives,
So that I can interact with the workflow layout exactly as designed in the reference visual.
Acceptance Criteria:
Visual Fidelity: Match the layout, spacing, typography, color palette, and UI components shown in the attached images 
Workflow Elements: Implement all interactive elements (e.g., step indicators, action buttons, cards, status badges, data tables, or forms) exactly as depicted in the mockup.
Component Accuracy: Ensure header controls, sidebars, and main content panels reflect the precise visual hierarchy of the screenshot.
User Story 3: Care Protocol Workflow UI
As a User,
I want to the susbsequent workflow of the items under  Care Protocol,
So that I can complete or monitor the protocol steps as shown in the visual reference.
Acceptance Criteria:
Visual Fidelity: Match the layout, styling, and design components shown in attached images

Design Accuracy: Replicate colors, pixel spacing, iconography, and font weights as close to 1:1 as possible based on the attached images.
